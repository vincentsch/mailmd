# mailmd disconnect

Remove an account and its saved login

## Usage

```
mailmd disconnect <account>
```

## Examples

```
mailmd disconnect work --dry-run
mailmd disconnect work
```

## Output

Shows text you can read in your terminal.

Use --json to get JSON for scripts and other programs.

## Preview changes

This command changes things. Add `--dry-run` to see what it would change; nothing changes then.
